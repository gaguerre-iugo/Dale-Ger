EL TREN

En esta actividad, cada estudiante debe clasificar palabras según comiencen con el sonido /m/ o con el sonido /n/.

  • La educadora presenta las tarjetas con imágenes y nombra cada una.
  • Coloca la letra M como referencia y propone identificar las palabras que comienzan con /m/.
  • Luego coloca la letra N y se repite el procedimiento con las palabras que comienzan con /n/.
  • Si hay dudas, se compara el sonido inicial de una palabra con el sonido de referencia.
  • Al finalizar, se cuentan las tarjetas de cada grupo y se comparan las cantidades.
MAPA, MOTO, MONEDA, MANZANA, MESA, NAVE, NIDO, NENE, NUDO.
